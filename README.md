# MudPilot

A MegaMUD-style automation client for MajorMUD, with MME (MajorMUD Explorer) built in.

**Download:** grab the latest zip from [Releases](https://github.com/MudPilot/MudPilot/releases/latest).

- **First install:** unzip anywhere and run `MudPilot.exe`.
- **Updating:** drop the new zip in your Downloads folder and restart MudPilot; it installs itself.

Questions and bug reports: the MudPilot Discord, #bug-reports. Or use **Report a problem** inside MudPilot.
